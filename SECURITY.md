# Security Policy

## Supported versions
Only the latest release is supported. Please update before reporting.

## Reporting a vulnerability
Use GitHub's *Report a vulnerability* (Security → Advisories), or open a
private issue if unavailable. Do **not** discuss security problems in
public issues.

Include: description, reproduction steps, affected component
(library/CLI/GUI/packaging), and impact assessment.

We acknowledge reports within 7 days and aim to ship fixes promptly.
This software is provided AS-IS for informational use; validate all outputs
before any GMP use (see LICENSE).
